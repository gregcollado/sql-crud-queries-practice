# Práctica SQL CRUD

Ejercicios de SQL realizados en **SQLite** para practicar:

- Tablas `cliente`, `factura` y `recibo`.
- Claves primarias y foráneas.
- Consultas con `JOIN`, agrupaciones y agregaciones.
- Operaciones CRUD: `INSERT`, `DELETE` y `UPDATE`.

## Ejecución

Abrir `PRASQL.sql` en SQLite y ejecutarlo sobre una base de datos nueva:

```bash
sqlite3 prasql.db < PRASQL.sql
```
